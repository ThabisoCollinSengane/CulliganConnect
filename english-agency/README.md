# Online English Teaching Agency: planning workspace (working name TBD)

> This folder is a **separate project** from CulliganConnect. It lives here temporarily because this
> session can only push to this repository. Moving it to its own repo is recommended; the whole folder
> is self-contained.

## START HERE FIRST
0. **`ops/SALES-PLAYBOOK.md`**: viability verdict, how to approach each contact, scripts, objections, 90-day plan.
0. **`ops/BUSINESS-MODEL-RECOMMENDATION.md`**: the recommended name, products, pricing and growth stages. Use it with `ops/pricing-calculator.xlsx` (change the blue cells).
1. **`research/CHALLENGE-what-breaks.md`**: what is most likely to break, with the evidence that would settle each point.
2. **`HANDOVER.md`** (v2): the plan of record.
3. **`DECISIONS.md`**: what's decided, and the open decisions waiting on you.
4. **`ai-team/BLUEPRINT.md`**: your AI team, workflow, tool stack, QA plan and 7-day launch plan.

## Run the AI team
Open Claude Code **inside this `english-agency/` folder**. The main session acts as Chief of Staff
(`CLAUDE.md`), and the four specialists in `.claude/agents/` load automatically:
`market-researcher` · `prospect-builder` · `ops-planner` · `fact-checker`.
Nothing gets sent, spent, registered or published without your approval.
